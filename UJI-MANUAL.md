# Uji manual TUMBUH F&B v0.1.0

Lakukan setelah aplikasi dibuka dari alamat HTTPS GitHub Pages. Ini adalah skenario uji, bukan klaim bahwa semua tes sudah lulus.

## 1. Data contoh dan HPP
Data contoh Es Teh:
- Teh: 3 g × Rp40/g = Rp120
- Gula: 15 g × Rp18/g = Rp270
- Gelas + tutup: 1 pcs × Rp300/pcs = Rp300
- **HPP per porsi yang diharapkan: Rp690**
- Harga jual contoh: Rp5.000
- **Laba kotor per porsi yang diharapkan: Rp4.310**

Buka menu Produk dan cocokkan HPP Es Teh. Jika berbeda, hentikan pengujian dan catat hasilnya.

## 2. Transaksi tunai
1. Buka Kasir, tambahkan 1 Es Teh.
2. Pilih pembayaran Tunai dan simpan.
3. Buka Laporan.
4. Cocokkan omzet Rp5.000, HPP terjual Rp690, laba kotor Rp4.310, dan laba bersih Rp4.310 (belum ada biaya operasional).
5. Buka Stok. Teh seharusnya berkurang 3 g, gula 15 g, gelas 1 pcs.

## 3. Pengeluaran dan kas
1. Catat pengeluaran operasional tunai Rp1.000.
2. Laba bersih yang diharapkan menjadi Rp3.310.
3. Kas tunai berubah sesuai kas awal + penjualan tunai − pengeluaran tunai − pembelian stok tunai.
4. Catat pembelian bahan tunai sebagai stok masuk. Pastikan pembelian stok mengurangi kas tunai tetapi tidak langsung mengurangi laba bersih bulan itu.

## 4. Penyimpanan dan offline
1. Muat aplikasi saat online sampai seluruh tampilan selesai.
2. Tutup lalu buka lagi; transaksi tadi harus tetap ada.
3. Aktifkan mode pesawat, buka kembali aplikasi dari ikon layar utama.
4. Coba tambah satu transaksi. Pastikan tersimpan setelah aplikasi ditutup dan dibuka lagi.
5. Jika layar tidak terbuka atau transaksi tidak tersimpan, catat tipe HP, versi Android, browser, dan langkah yang dilakukan.

## 5. Backup dan pemulihan
1. Buka Pengaturan → Unduh backup JSON.
2. Pastikan file tersimpan di HP.
3. Hapus data contoh hanya pada salinan uji, atau ubah satu catatan setelah backup.
4. Pulihkan file backup dan pastikan data kembali sesuai.
